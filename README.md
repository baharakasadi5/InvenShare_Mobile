# InvenShare Mobile  
A modern, production-ready mobile app for the InvenShare / Inventool.ai innovation platform — built with Flutter and designed for scalability, clean architecture, and real-world deployment.

---

## 📌 Overview  
InvenShare Mobile enables inventors to create, organize, and refine their ideas with an AI-assisted workflow.  
The app provides a clean, intuitive interface for managing invention data, viewing AI insights, and interacting with backend services.

This project demonstrates:
- Professional Flutter development  
- Modular architecture  
- API-driven mobile design  
- Real product development (not a tutorial project)

---

## 🚀 Features  
- User authentication (Login / Signup)  
- Create & manage inventions  
- View invention details  
- AI-powered idea suggestions (coming soon)  
- Modern Material 3 UI  
- Clean, scalable project structure  

---

## 🧱 Tech Stack  
- Flutter (Dart)  
- Material 3  
- REST API (FastAPI backend)  
- State management: Provider / Riverpod / Bloc  
- AI-assisted development
